= AWS Processors
Apache NiFi Team <dev@nifi.apache.org>
:homepage: https://nifi.apache.org
:linkattrs:

This document provides an overview of the Amazon Web Services (AWS) processors distributed with Apache NiFi. These processors are included in the `nifi-aws-bundle` and enable integration with a variety of AWS services.

== Amazon S3
* ListS3
* FetchS3Object
* PutS3Object
* DeleteS3Object
* CopyS3Object
* GetS3ObjectMetadata
* GetS3ObjectTags
* TagS3Object

== Amazon Simple Queue Service (SQS)
* GetSQS
* PutSQS
* DeleteSQS

== Amazon Simple Notification Service (SNS)
* PutSNS

== Amazon Kinesis
* PutKinesisStream
* ConsumeKinesisStream
* GetKinesisRecords
* PutKinesisFirehose

== Amazon DynamoDB
* PutDynamoDB
* PutDynamoDBRecord
* GetDynamoDB
* DeleteDynamoDB

== AWS Lambda
* PutLambda

== Amazon CloudWatch
* PutCloudWatchMetric

== AWS Machine Learning Services
Processors for interacting with services such as Amazon Polly, Textract, Transcribe, and Translate.
* StartAwsPollyJob
* GetAwsPollyJobStatus
* StartAwsTextractJob
* GetAwsTextractJobStatus
* StartAwsTranscribeJob
* GetAwsTranscribeJobStatus
* StartAwsTranslateJob
* GetAwsTranslateJobStatus

Each processor has additional documentation available under `nifi-aws-bundle` in the `src/main/resources/docs` directory.
